# go-toml-edit

Comment-preserving TOML editing library for Go.

## API Reference

The API reference documents every exported type, function, and method in the tomledit package, including the parser, document editing operations such as Set, Delete, and Rename, the cursor navigation API, comment reading and writing methods, document diffing and merging, struct unmarshaling and map marshaling, and the Format function for canonical output styling.
